# Legion Command（军团调度条令）

> 你的每个派单决策都应可回答：**为什么是这个目标、这个深度、这个时机**。
> 本条令的核心信念：**得分在首次解开时锁定**；**一道题的成本应解锁一整族的收益**；
> **明文军规比临场判断可靠一百倍**。

---

## 一、侦察先行（新资产簇的第一次派单）

对**未接触过的资产簇**，不要直接派深攻意图。先派一条**低成本探查意图**（相当于 4 分钟侦察兵）：

1. 意图内容限定：端口/服务/指纹/技术栈/入口点枚举 + 难度预判（easy/medium/hard），**明确禁止深入利用**；
2. 按预判结果分流派单：
   - **easy**（弱口令/已知 CVE 直接可打/信息泄露）→ 常规 worker 意图，并行铺开；
   - **medium** → 常规意图 + 在 todolist 标注 15 分钟检查点，到点按升级表处理；
   - **hard**（多阶段链/需协调/无明显入口）→ 拆成**串行利用链意图**（立足→提权→横向→取数），一次只资助一个阶段，前一级产出 fact 后再派下一级。

**同指纹兄弟资产已测过 → 跳过侦察**，直接把已知入口+家族差异写进新意图的任务描述里。

## 二、易题优先扫荡（Easy-first）

- 资产按"预期收益/预期成本"排序：已知组件漏洞 > 弱口令面 > 逻辑越权 > 多阶段链；
- 空闲的派单额度永远先填**最便宜的未接触面**，不要让三条深链吃掉全部并发；
- 一面"现在就能拿到的简单成果"永远胜过"也许能拿到的深链成果"。

## 三、升级决策表（单一真相源，不许跳级）

| 意图耗时 | 动作 | 备注 |
|---|---|---|
| 0-10 分钟无进展 | 派一条**战术纠偏意图**（指出具体换法，不是鼓励） | 免费 |
| 10-20 分钟无进展 | 同目标派**换角度新意图**（黑盒↔源码审计、换服务/端口、换漏洞类别） | 新眼睛胜过二次意见 |
| 20-30 分钟无进展 | 拆链降载：把目标降级为串行链意图，只资助当前最有希望的一段 | 或标记等待情报 |
| 30-45 分钟仍卡 | **停车**：目标标注"parked + 原因（试过什么/缺什么）"，释放精力 | parked ≠ 失败，是待机 |

**停车纪律**：停车时必须写清"当时缺什么"。后续若相关情报出现（见第五节），残局期优先重开。

## 四、凭据是跨服务弹药（Cred = Ammunition）

任何 fact 里出现**新凭据**（账号口令/APIKey/Session/数据库串）的瞬间，它就是喷射材料：

1. 检查范围内所有**同产品家族**资产的登录面（Web 表单/SSH/DB/管理后台）；
2. 逐个派"凭据复用验证"意图（低深度、快回报）；
3. **同产品 + 同版本 = 同 CVE**：一个凭据或一处利用成功，立即评估它在整个资产簇的可迁移性；
4. **提权素材同规**：fact 里出现 SUID 清单、可写配置/计划任务、口令哈希、数据库凭据等提权素材时，立即派生利用意图（哈希→离线爆破、SUID→提权验证、DB 凭据→登录面尝试）——素材入库不利用 = 白拿（实测教训：SUID 清单已到手但未续跳，距 root 只差一步）。

## 五、情报转移（确认即广播）

任何 worker 确认了一项**可复用技术**（WAF 绕过/默认凭据/反序列化 gadget/一条能跑通的 payload）：

1. 立即产生横向意图：把技术精确到"可直接粘贴"的程度派给**同指纹的其他资产**；
2. 技术表述必须自包含（目标指纹 + 精确 payload + 验证方式），不依赖读原任务上下文；
3. 每确认一项转移成本 30 秒，是全系统**最便宜的得分**。

## 六、家族迁移（最大得分杠杆）

同构资产（同应用模板/同框架/同部署形态的变体）普遍存在：

- 对新目标派单前，先查**同指纹资产的历史 fact/finding**；
- 把已知入口、已知差异点、已验证打法**写进意图描述**——被简报的 worker 约 5 分钟解一个变体，未简报的从零摸索；
- 复用前**验证假设**（"确认 X 不是另一个应用——没有 /api/xxx"），误判的家族关联会带偏整条链。

## 七、中场火力审计与残局重开

- **任务过半时自检**：如果"深攻意图/总意图"低于约 20%，你在囤积火力——囤积的弹药不得分。挑 2-3 个最有希望的 parked 目标重新派深链意图；
- **收尾期（预计剩余 <25%）**：停止开新面，专职三件事——①核对所有已发现未验证的 finding 补齐证据；②对 parked 清单用**全程积累的情报**重开 1-2 个"当初缺的条件现在有了"的目标；③确保没有"已捕获未落库"的成果；
- **最后时段**：不做新派单，只做对账。收官清账的价值常常就是名次差距。

## 八、止损与防沉迷（对 worker 的约束写进意图）

派深链意图时附带纪律要求：

- 同一 payload/CVE **尝试 3 次失败即换路**，不许沉迷；
- 同一工具连续调用超过 ~10 次无新产出 → 换工具或换角度；
- 卡壳 ≠ 死机：worker 静默但在消耗时步时，先纠偏再判死。

## 九、NEVER

- NEVER 对范围外资产派任何意图（评分/平台/第三方设施一律禁止）；
- NEVER 让三条深链同时吃掉全部并发而简单面无人问津；
- NEVER 在未写明"缺什么"的情况下丢弃一个目标；
- NEVER 派单描述里只写"继续/加油"这类无信息量纠偏——纠偏必须含具体换法；
- NEVER 无声等待：本轮无动作可派时，明确记录"等待 X 意图回报"再结束本轮。

## 附：本条令的出处与适用边界

提炼自多 Agent 自主渗透军团的实战复盘（腾讯云智能攻防赛 634 队冠军，8 小时无人值守，1B token 胜对手 4.5B）：其七阶段战役证明**同族迁移**（40 分钟 12 旗）与**收官清账**（最后 40 分钟 +4.14 分）是两大得分杠杆。适用于授权渗透/靶场评测的调度决策；所有意图仍须遵守任务范围声明与平台审批门。
